# Продуктовая логика и руководство: UrFU Deadline Tracker

## 1. Проблема
У студентов ИРИТ-РТФ дедлайны разбросаны по разным источникам: Moodle, БРС, чаты старост в Telegram и личные заметки. Из-за этого легко пропустить сдачу лабораторной работы или контрольной точки.

## 2. Решение
**UrFU Deadline Tracker** — единый дашборд для контроля всех учебных задач с цветовыми индикаторами срочности и фильтрацией по предметам.

## 3. Основные статусы и приоритеты
- 🔴 **Горящий дедлайн (< 24 часов):** подсвечивается вверху списка.
- 🟡 **На этой неделе:** плановые лабораторные и домашние задания.
- 🟢 **Сдано / Зачтено:** архив выполненных работ для контроля баллов БРС.

## 4. Ключевые функции (MVP)
- Быстрое добавление задачи (Предмет, Название лабы, Дата сдачи, Сложность).
- Фильтрация по дисциплинам (Программирование, Матанализ, Базы данных, Сети).
- Кнопка экспорта дедлайнов в стандартный календарь (`.ics`).
